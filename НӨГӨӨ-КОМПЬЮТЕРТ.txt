НӨГӨӨ КОМПЬЮТЕРТ ТОХИРУУЛАХ
==========================

Файл илгээх ШААРДЛАГАГҮЙ. Бүх зүйл GitHub дээр байгаа.
Доорх НЭГ мөрийг хуулж, PowerShell дээр наагаад Enter дар.


АЛХАМ 1 — Git, Node.js суулгах (анх удаа л)
-------------------------------------------
   https://git-scm.com/download/win
   https://nodejs.org         ("LTS" товчийг дар)

   Хоёуланг нь суулгаад компьютероо ДАХИН АСААНА.


АЛХАМ 2 — Энэ нэг мөрийг PowerShell-д наа
------------------------------------------
   (Start товч → "powershell" гэж бич → Enter)

git clone https://github.com/monoshuns07-glitch/monos-hab-lms.git D:\monos-hab-lms; cd D:\monos-hab-lms; powershell -ExecutionPolicy Bypass -File TOHIRUULAH.ps1


   D: диск байхгүй бол D:\monos-hab-lms гэснийг
   C:\monos-hab-lms болгож солино (хоёр газарт нь).


ДУУСЛАА
-------
Desktop дээр 4 товчлуур гарна:

   ХАБЭА 1 - ТАТАХ        нөгөө комын ажлыг авна
   ХАБЭА 2 - ХӨГЖҮҮЛЭХ    локал сервер + браузер нээнэ
   ХАБЭА 3 - ИЛГЭЭХ       сайт руу гаргана
   ХАБЭА - ХАВТАС         кодын хавтсыг нээнэ


ТОКЕН ХЭРЭГГҮЙ
--------------
Анх удаа "ИЛГЭЭХ" дарахад браузер нээгдэж GitHub-д
нэвтрэхийг хүснэ. Нэг л удаа нэвтэрнэ, дараа нь санана.
Нууц түлхүүр хуулж явуулах шаардлагагүй.

------
