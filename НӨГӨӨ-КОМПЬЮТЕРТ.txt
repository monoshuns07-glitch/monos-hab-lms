2-ИЛГЭЭХ.bat хоёрыг дарж ажиллана.


─── АЛХАМ 1. Git суулгах ───────────────────────────────────────

  https://git-scm.com/download/win  →  татаад суулгана
  (Бүх асуултад Next дараад л болно)

  Шалгах: Start → "cmd" бичээд нээгээд:
      git --version
  Хувилбар гарвал болсон.


─── АЛХАМ 2. Төслийг татах ────────────────────────────────────

  cmd нээгээд дараах 2 мөрийг хуулж тавина:

      d:
      git clone https://github.com/monoshuns07-glitch/monos-hab-lms.git D:\monos-hab-lms

  ⚠ ЧУХАЛ: OneDrive ДОТОР бүү тавь. OneDrive нь git-ийг эвдэнэ.
     D:\ эсвэл C:\ дээр шууд байрлуулна.


─── АЛХАМ 3. Мөрийн төгсгөлийг тааруулах ──────────────────────

  cmd дээр:

      cd /d D:\monos-hab-lms
      git config core.autocrlf false
      git config core.eol lf
      git config user.name "Buyant"
      git config user.email "buyant.so@monos.mn"
      git rm --cached -r .
      git reset --hard

  ⚠ Энэ алхмыг ЗААВАЛ хийнэ. Эс бөгөөс script.js (1.1 МБ) файл
     бүхэлдээ өөрчлөгдсөн мэт харагдаж, хоёр компьютер хоорондоо
     байнга зөрчилдөнө.


─── АЛХАМ 4. Илгээх эрх өгөх ──────────────────────────────────

  GitHub токен хэрэгтэй. Энэ компьютер дээрх токеныг олох нь:

      C:\Users\buyant.so\OneDrive - monos\Attachments\File\.git\config

  файлыг Notepad-аар нээж, https:// ба @github.com хоёрын хооронд
  байгаа урт үсэг тоог хуулна (ghp_ эсвэл github_pat_ гэж эхэлнэ).

  Дараа нь нөгөө компьютер дээр cmd-д (ТОКЕН гэдгийг солино):

      cd /d D:\monos-hab-lms
      git remote set-url --push origin https://ТОКЕН@github.com/monoshuns07-glitch/monos-hab-lms.git

  ⚠ Энэ токеныг хэнд ч бүү үзүүл, чатад бүү бич, файлд бүү хадгал.
     Repo нь НИЙТЭД НЭЭЛТТЭЙ тул токен цацагдвал хэн ч сайтыг
     өөрчилж чадна.


─── АЛХАМ 5. Товчлууруудыг хуулах ─────────────────────────────

  Энэ компьютер дээрх дараах 2 файлыг USB эсвэл мэйлээр
  нөгөө компьютерын D:\monos-hab-lms дотор хуулна:

      1-ЭХЛЭХ.bat
      2-ИЛГЭЭХ.bat
